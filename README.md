### 🧠 What is it

**CineSearch** is a modern, fast, and responsive movie and TV show discovery web application that allows users to explore the entertainment world in real time. 

It lets users:
- 🔍 Search for movies with instant debounced search
- 🔥 Browse trending movies powered by TMDB
- 🎬 View detailed movie information in an elegant modal
- 🎭 Access comprehensive metadata using **The Movie Database (TMDB)** API

Built with **React 19**, **Vite**, **Tailwind CSS 4**, and **TMDB API**, CineSearch delivers a smooth and polished user experience with no external backend dependencies.

---

### ✨ Features

- **Real-time Search** - Debounced search for instant results
- **Trending Movies** - Discover what's hot right now via TMDB's trending endpoint
- **Movie Details Modal** - Click any movie to see full details including backdrop, genres, runtime, and overview
- **Responsive Design** - Optimized for mobile, tablet, and desktop
- **Modern UI** - Clean, dark-themed interface with smooth animations
- **Fast Performance** - Built with Vite for lightning-fast development and builds

---

### 🛠️ Tech Stack

- **Frontend:** React 19, Vite 8
- **Styling:** Tailwind CSS 4
- **API:** TMDB API
- **Utilities:** react-use for debouncing

---

### 🚀 Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Create a `.env` file and add your TMDB API key:
   ```env
   VITE_APP_API_KEY=your_tmdb_bearer_token
   ```
4. Start the dev server: `npm run dev`
5. Build for production: `npm run build`
